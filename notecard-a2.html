Assessment 2 · Math formula ↔ Excel

Rates as decimals (5% → 0.05). Excel: use cell refs like A1; ^ and POWER both raise to a power.

Probability

FormulaExcel
P = fav ÷ total basic · equally likely =fav/total
P(not A) = 1 − P(A) complement =1−pA
P(A and B) = P(A)·P(B) independent =pA*pB
P(A or B) = P(A)+P(B) mutually exclusive =pA+pB
P(A or B) = P(A)+P(B)−P(A and B) inclusive OR =pA+pB−pBoth
without replacement 2nd draw: one fewer =(r/t)*((r−1)/(t−1))

Counting

FormulaExcel
n! = n·(n−1)···1 factorial =FACT(n)
P(n,r) = n!/(n−r)! order matters · perm =PERMUT(n,r)
C(n,r) = n!/(r!(n−r)!) order doesn’t · comb =COMBIN(n,r)

Calc keys: nPr / nCr · Excel same idea as PERMUT / COMBIN.

Arithmetic sequences

FormulaExcel
d = an − an−1 common difference =B2−B1
an = a1 + (n−1)d explicit =a1+(n−1)*d
a1; an = an−1 + d recursive =B1+d  (fill down)
Sn = n(a1 + an)/2 finite series sum =n*(a1+an)/2

Geometric sequences

FormulaExcel
r = an ÷ an−1 common ratio =B2/B1
an = a1 · rn−1 explicit =a1*POWER(r,n−1)
a1; an = an−1 · r recursive =B1*r  (fill down)
Sn = a1(1−rn)/(1−r) r ≠ 1 =a1*(1−POWER(r,n))/(1−r)

Classify a sequence

  1. Subtract consecutive terms → constant? → arithmetic (d).
  2. Divide consecutive terms → constant? → geometric (r).
  3. Neither pattern → neither.

QUICK CHECK

{3, 7, 11, 15…} → d = 4

{2, 6, 18, 54…} → r = 3

  • Arithmetic ↔ add/subtract same amount
  • Geometric ↔ multiply/divide by same factor
  • Negative r → alternating signs

EXCEL POWER TIPS

  • POWER(base, exp) or base^exp
  • FACT(5) → 120
  • PERMUT(10,3) → 720
  • COMBIN(10,3) → 120
  • Lock a rate: $B$1 when filling

Linear · exponential · interest · Excel twins

Linear adds a constant; exponential multiplies by a constant. Interest: simple = linear-ish; compound = exponential.

Linear & slope

FormulaExcel
m = (y2−y1)/(x2−x1) slope · rise/run =(y2−y1)/(x2−x1) or =SLOPE(ys,xs)
f(x) = mx + b slope-intercept =m*x+b
d(t) = rate·t + start word-problem linear =rate*t+start
from table: b at x=0; m = Δy/Δx =SLOPE(y-range,x-range) =INTERCEPT(y,x)

Exponential

FormulaExcel
f(n) = a · rn a = start; r = factor =a*POWER(r,n)
growth: r = 1 + pct 8% → r = 1.08 =1+pct
decay: r = 1 − pct 12% → r = 0.88 =1−pct

Interest

FormulaExcel
A = P(1 + rt) simple interest =P*(1+r*t)
A = P(1 + r)t compound once/year =P*POWER(1+r,t) or =FV(r,t,0,−P)

WHICH MODEL?

  • Constant add each step → linear / arithmetic
  • Constant multiply each step → exp / geometric
  • Simple interest → A = P(1+rt)
  • Compound interest → A = P(1+r)t
a₁ first term d difference r ratio/rate n index / years P principal POWER · FACT · PERMUT · COMBIN · FV · SLOPE
